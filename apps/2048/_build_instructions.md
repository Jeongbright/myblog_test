# Build 서브에이전트 작업 지시서

## 목적
`apps/2048/spec.md`에 정의된 스펙대로 2048 게임 웹앱을 실제로 구현한다.

## 범위 (반드시 지킬 것)
- 수정/생성 가능한 파일: `apps/2048/index.html`, `apps/2048/style.css`, `apps/2048/script.js` 뿐.
- 그 외 블로그의 어떤 파일도 건드리지 않는다 (`index.html`, `css/`, `js/`, `posts/`, 루트 `CLAUDE.md` 등 전부 read-only로 취급).
- 새 폴더나 별도 하위 폴더를 만들지 않는다. `apps/2048/` 바로 아래에 3개 파일만 만든다.

## 해야 할 일
1. `apps/2048/spec.md`를 정독한다.
2. spec.md에 정의된 파일 구조, DOM 구조, state 구조, 함수 목록, 이벤트 흐름, UI/디자인 방향을 그대로 따라 `index.html`, `style.css`, `script.js`를 작성한다.
3. 프레임워크 없이 순수 HTML/CSS/JS로 작성한다. 외부 라이브러리/CDN을 쓰지 않는다.
4. 다음 기능이 실제로 동작해야 한다:
   - 4x4 격자, 시작 시 타일 2개 랜덤 생성
   - 방향키(↑↓←→)로 타일 이동/병합, 점수 갱신
   - 모바일 터치 스와이프로도 동일하게 동작
   - 점수판(현재 점수 + 최고 점수, localStorage 저장)
   - 게임 오버 / 승리(2048 등장) 판정과 오버레이 표시
   - "새 게임" 버튼으로 재시작
5. 구현 중 spec.md와 다르게 판단이 필요한 부분이 생기면(예: 특정 애니메이션 방식), spec의 의도를 최대한 지키는 선에서 합리적으로 결정하고 무엇을 어떻게 바꿨는지 최종 보고에 남긴다.

## 하지 말아야 할 것
- spec.md에 없는 새로운 기능(예: 서버 저장, 랭킹 공유 등)을 추가하지 않는다.
- 블로그의 다른 파일을 수정하지 않는다.
- 커밋하지 않는다 (커밋은 이후 Embed 단계에서 처리한다).

## 완료 조건
`apps/2048/index.html`, `style.css`, `script.js`가 모두 작성되고, 브라우저에서 열었을 때 기본 동작(타일 이동/병합/점수/게임오버/재시작)이 되는 상태. 완료 후 무엇을 만들었는지, spec과 달라진 부분이 있으면 무엇인지 간단히 보고할 것 (300단어 이내).
