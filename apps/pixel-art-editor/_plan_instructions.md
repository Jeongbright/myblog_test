# Plan 서브에이전트 작업 지시서

## 목적
사용자가 요청한 웹앱: "픽셀 아트 에디터" — 16x16 격자에 도트를 찍어 그림을 그리고, 완성하면 PNG로 저장할 수 있는 도구. 색상 팔레트 포함.

## 프로젝트 컨텍스트
- 이 저장소(`my_blog`)는 마크다운 블로그 + 미니 웹앱 포트폴리오. 저장소 루트의 `CLAUDE.md`를 먼저 읽고 규칙을 파악할 것.
- 참고로 `apps/2048/`에 먼저 만든 웹앱과 그 `spec.md`가 있으니, 파일 구조나 문서화 스타일을 참고해도 좋다 (단, 이 앱은 완전히 새로 설계할 것).
- 웹앱은 `/apps/pixel-art-editor/` 폴더 안에 독립적으로 만들어야 하며, 블로그의 다른 파일(`index.html`, `css/`, `js/`, `posts/`, 다른 `apps/*`)은 건드리지 않는다.
- 프레임워크 없이 순수 HTML/CSS/JS. 외부 라이브러리는 최소화한다 (CDN은 허용되지만, PNG 저장은 브라우저 내장 Canvas API(`canvas.toDataURL` / `canvas.toBlob`)만으로 충분히 구현 가능하므로 외부 라이브러리 없이 설계할 것).
- 모바일에서도 사용 가능해야 한다 (터치로 도트 찍기 등 고려).

## 해야 할 일
1. `apps/pixel-art-editor/` 폴더에 들어갈 파일 구조를 설계한다 (예: `index.html`, `style.css`, `script.js`).
2. 핵심 기능을 어떻게 구현할지 정리한다:
   - 16x16 격자: 각 칸을 클릭(또는 드래그, 터치)하면 현재 선택된 색으로 칠해짐
   - 드래그로 여러 칸을 연속으로 칠하는 것(마우스 down 상태에서 이동, 터치 이동)까지 지원할지 결정하고 명시
   - 색상 팔레트: 미리 정의된 색상 목록(스와치)에서 선택 + 커스텀 색상 선택(`<input type="color">`) 지원 여부 결정
   - 지우개 기능(칸을 투명/배경색으로 되돌리기)
   - 전체 지우기(Clear) 버튼
   - 격자를 실제로 어떤 방식으로 렌더링할지 결정: `<canvas>` 하나로 그릴지, 16x16 `<div>`(또는 `<button>`) DOM 격자로 만들지 각각의 장단점을 고려해 하나를 선택 (PNG 저장을 고려하면 내부적으로 `<canvas>`를 데이터 소스로 쓰는 편이 유리함 — 화면 표시는 DOM 격자로 하되 저장 시점에 canvas에 그려서 내보내는 방식도 가능, 혹은 처음부터 canvas 하나로 그리기와 표시를 겸하는 방식도 가능. 가장 단순하고 버그가 적은 방식을 선택해 명시할 것)
   - PNG로 저장: 완성 버튼(또는 "PNG로 저장" 버튼) 클릭 시 16x16 데이터를 canvas에 그리고 `canvas.toDataURL("image/png")` → 다운로드 링크(`<a download>`)를 통해 저장. 실제 다운로드 파일은 16x16 그대로가 아니라 배율을 키워서(예: 16배 확대한 256x256) 저장하는 것이 보기 좋음 — 이 부분을 spec에 구체적으로 명시할 것 (원본 16x16 해상도로 저장할지, 확대해서 저장할지 결정하고 이유를 적을 것).
   - 실행 취소(undo) 여부는 이번 범위에 넣지 않아도 됨(넣고 싶으면 간단한 스택 방식으로 제안 가능, 필수는 아님을 명시).
3. UI/디자인 방향을 정리한다 (레이아웃: 격자 + 팔레트 + 도구 버튼들을 어떻게 배치할지, 색상, 반응형 방식). 블로그 톤(`css/style.css`)과 크게 어긋나지 않되, 앱은 독립적이므로 자체 스타일을 가져도 된다.
4. 위 내용을 종합해 `apps/pixel-art-editor/spec.md` 파일로 저장한다. `spec.md`는 이후 별도의 Build 서브에이전트가 그대로 구현 지침으로 사용하므로, 파일별로 무엇을 넣을지 최대한 구체적으로 적는다 (함수/상태 구조, DOM 구조, 이벤트 처리 흐름 등).

## 하지 말아야 할 것
- 실제 코드(`index.html`, `script.js` 등)를 작성하지 않는다. 이번 단계는 계획(`spec.md`)만 작성한다.
- 블로그의 다른 파일이나 `apps/2048/`을 수정하지 않는다.

## 완료 조건
`apps/pixel-art-editor/spec.md` 파일이 작성되면 작업 완료. 완료 후 spec의 핵심 요약을 간단히 보고할 것.
