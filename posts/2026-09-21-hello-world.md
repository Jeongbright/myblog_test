프레임워크 없이 순수 HTML, CSS, JavaScript로 만든 블로그입니다. 마크다운 파일 하나만 추가하면 별도 빌드 과정 없이 바로 글이 게시됩니다.

## 이 블로그의 특징

- 다크모드를 지원합니다. 오른쪽 위 버튼으로 전환할 수 있고, 선택한 테마는 저장됩니다.
- 모바일 화면에서도 읽기 편하도록 반응형으로 만들었습니다.
- 새 글은 `posts/` 폴더에 마크다운 파일을 추가하고 `posts.json`에 한 줄만 추가하면 됩니다.

## 코드 예시

```js
function greet(name) {
  return `안녕하세요, ${name}!`;
}
```

> 글쓰기에만 집중할 수 있는 가벼운 블로그를 목표로 합니다.
