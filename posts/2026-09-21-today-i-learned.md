클로드 코드와 함께 이 블로그를 처음부터 만들면서, HTML·CSS·JavaScript가 각자 어떤 역할을 맡는지 다시 한 번 정리하게 되었습니다.

## HTML — 구조와 의미

HTML은 페이지에 어떤 내용이 어떤 순서와 의미로 존재하는지를 정의합니다. 이 블로그에서는 `index.html`이 글 목록의 뼈대를, `post.html`이 글 상세 페이지의 뼈대를 담당합니다. `<header>`, `<main>`, `<article>` 같은 태그로 영역의 역할을 명확히 해두면, 스타일이나 스크립트가 없어도 문서의 구조 자체가 이해하기 쉬워집니다.

## CSS — 스타일과 레이아웃

CSS는 그 구조에 어떤 모습을 입힐지 결정합니다. `style.css`에서는 색상 값을 `--bg`, `--text`, `--accent` 같은 CSS 변수로 관리하고, `data-theme` 속성에 따라 그 변수 값만 바꿔서 라이트/다크 테마를 전환했습니다. 본문 폭을 제한하고 줄간격을 넉넉히 주는 것만으로도 읽기 편한 느낌이 크게 달라진다는 것도 체감했습니다.

## JavaScript — 동작과 상호작용

JavaScript는 정적인 문서를 살아있게 만드는 역할을 합니다. `main.js`는 `posts.json`을 읽어와 글 목록을 그려주고, `post.js`는 마크다운 파일을 가져와 HTML로 변환해 보여줍니다. `theme.js`는 사용자가 고른 테마를 `localStorage`에 저장해 새로고침해도 유지되게 합니다. 결국 JS는 "데이터를 가져와서 화면에 반영하고, 사용자의 선택을 기억하는" 역할을 맡고 있었습니다.

## 정리

세 언어는 역할이 뚜렷하게 나뉘어 있었습니다.

- HTML: 무엇이 있는가 (구조)
- CSS: 어떻게 보이는가 (표현)
- JavaScript: 어떻게 동작하는가 (행동)

프레임워크 없이 직접 조합해보니, 평소 프레임워크가 대신 처리해주던 부분들이 실제로는 이 세 가지의 조합이었다는 걸 더 분명하게 느낄 수 있었습니다.
