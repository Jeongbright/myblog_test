미디어 쿼리로 화면 크기별 폰트 크기를 일일이 지정하다 보면 코드가 금방 지저분해집니다. CSS `clamp()`를 쓰면 최소값과 최대값 사이에서 화면 크기에 따라 부드럽게 늘어나는 반응형 타이포그래피를 미디어 쿼리 없이 만들 수 있습니다.

## 기본 문법

`clamp(최소값, 선호값, 최대값)` 형태로 사용합니다. 선호값에 뷰포트 단위(`vw`)를 넣으면 화면이 커질수록 값이 커지되, 최소·최대 범위를 벗어나지 않습니다.

```css
h1 {
  font-size: clamp(1.5rem, 4vw + 1rem, 3rem);
}
```

이 코드는 화면이 아주 좁을 때는 1.5rem, 아주 넓을 때는 3rem으로 고정되고, 그 사이에서는 뷰포트 너비에 비례해 자연스럽게 커집니다.

## 왜 `vw` 단독 대신 `4vw + 1rem`을 쓰나요

`vw`만 쓰면 사용자가 브라우저 글꼴 크기를 확대해도 텍스트가 커지지 않아 접근성에 좋지 않습니다. `rem`을 함께 더해주면 사용자 설정도 반영되면서 화면 크기에 따른 변화도 유지됩니다.

## 여백에도 활용

폰트 크기뿐 아니라 패딩이나 마진에도 같은 방식으로 적용할 수 있습니다.

```css
.container {
  padding-inline: clamp(1rem, 5vw, 4rem);
}
```

## 정리

`clamp()`는 미디어 쿼리 여러 줄을 한 줄로 줄여주면서도 더 부드러운 반응형 결과를 만들어냅니다. 다만 값 계산이 직관적이지 않을 수 있으니, 최소·최대·중간 지점의 실제 렌더링 결과를 브라우저 개발자 도구에서 꼭 확인해보는 것이 좋습니다.
