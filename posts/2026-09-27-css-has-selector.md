JavaScript 없이는 불가능하다고 여겨졌던 "부모가 자식 상태에 따라 스타일을 바꾸는" 일을 CSS `:has()` 선택자로 할 수 있습니다. 관계 선택자에 조건을 걸 수 있게 해주는 의사 클래스로, 최신 브라우저에서 폭넓게 지원됩니다.

## 기본 사용법

`:has()` 안에 넣은 선택자와 일치하는 요소가 하나라도 있으면 바깥 선택자가 매치됩니다.

```css
/* 이미지가 있는 카드에만 여백 추가 */
.card:has(img) {
  padding-top: 0;
}
```

## 폼 유효성 스타일링에 활용

체크박스 상태에 따라 폼 전체의 배경을 바꾸는 것도 JS 없이 가능합니다.

```css
form:has(input:invalid) {
  border-color: crimson;
}

form:has(input:checked) {
  background: #f0fdf4;
}
```

## 형제 선택자처럼도 사용

`:has()`는 이전 형제를 선택할 수 없다는 CSS의 오랜 한계도 우회합니다.

```css
/* 다음에 h2가 오는 모든 p에 여백 추가 */
p:has(+ h2) {
  margin-bottom: 2rem;
}
```

## 정리

`:has()`는 성능 비용이 있을 수 있으니 너무 넓은 범위(`body:has(...)` 같은)보다는 구체적인 컨테이너에 좁혀서 사용하는 것이 좋습니다. 지원하지 않는 구형 브라우저 대응이 필요하다면 `@supports selector(:has(a))`로 분기 처리할 수 있습니다.
