마우스로 버튼을 클릭했을 뿐인데 굵은 파란색 아웃라인이 생기는 걸 본 적 있을 겁니다. 그게 싫어서 `outline: none`으로 포커스 스타일을 아예 지워버리면, 이번엔 키보드로 탭 이동하는 사용자가 지금 포커스가 어디 있는지 전혀 알 수 없게 됩니다. `:focus-visible`은 이 둘을 분리해서, 브라우저가 "키보드 탐색처럼 보이는 상황"일 때만 포커스 스타일을 적용하게 해줍니다.

## 기본 사용법

```css
/* 마우스 클릭이든 키보드든 항상 적용 (레이아웃 유지용으로만 사용) */
button:focus {
  outline: none;
}

/* 키보드 등으로 포커스되었을 때만 보이는 스타일 */
button:focus-visible {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}
```

마우스로 클릭했을 때는 `:focus-visible`이 매치되지 않아 아웃라인이 생기지 않고, Tab 키로 이동했을 때는 매치되어 아웃라인이 보입니다. 어떤 입력 방식이 "키보드스럽다"고 판단할지는 브라우저가 휴리스틱으로 정하므로, 직접 분기 로직을 짤 필요가 없습니다.

## 주의할 점

`:focus` 규칙을 완전히 지우지 말고 `:focus-visible`만 추가하는 쪽을 권합니다. 구형 브라우저는 `:focus-visible`을 모르기 때문에, `:focus`만 믿고 쓰면 그 브라우저에서는 포커스 스타일이 아예 사라집니다. 또한 `outline`을 지울 땐 `outline-offset` 같은 보조 속성도 같이 날아가니, 디자인상 아웃라인 대신 다른 시각적 표시(테두리, 그림자 등)를 쓰더라도 포커스 자체가 안 보이는 상태로 만들지 않는 것이 접근성의 핵심입니다.
