## CSS text-wrap: balance로 제목 줄바꿈 깔끔하게 만들기

제목이나 카드 헤드라인처럼 짧은 텍스트가 여러 줄로 넘어갈 때, 마지막 줄에 단어 하나만 덩그러니 남거나 줄 길이가 들쭉날쭉해지는 경우가 많습니다. `text-wrap: balance`를 지정하면 브라우저가 줄바꿈 위치를 자동으로 계산해서 각 줄의 길이를 최대한 균형 있게 맞춰줍니다.

```css
h1, h2, .card-title {
  text-wrap: balance;
}
```

내부적으로 여러 줄바꿈 조합을 시도해 가장 균형 잡힌 결과를 찾는 방식이라 연산 비용이 있고, 그래서 브라우저는 짧은 텍스트(대략 4~6줄 이하)에만 적용하도록 권장합니다. 본문처럼 긴 텍스트에는 비슷한 취지의 `text-wrap: pretty`를 쓰면 성능 부담 없이 마지막 줄의 고아 단어(orphan)만 줄여줍니다. 둘 다 비교적 최근에 추가된 속성이라 구형 브라우저에서는 그냥 무시되므로, 지원 여부와 상관없이 레이아웃이 깨지지 않는다는 점을 살려 progressive enhancement로 적용하면 됩니다.
