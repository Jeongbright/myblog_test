## CSS :is()와 :where()로 선택자 중복 줄이고 명시도 관리하기

비슷한 선택자를 여러 번 반복해서 쓴 CSS, 흔히 보셨을 겁니다.

```css
header h1, header h2, header h3,
footer h1, footer h2, footer h3 {
  font-weight: 700;
}
```

`:is()`를 쓰면 이런 조합을 훨씬 짧게 줄일 수 있습니다.

```css
:is(header, footer) :is(h1, h2, h3) {
  font-weight: 700;
}
```

여기서 `:is()`와 `:where()`의 차이를 아는 게 중요합니다. 둘 다 괄호 안 선택자 목록 중 가장 복잡한 것의 명시도를 그대로 가져가는 반면, `:where()`는 명시도가 항상 0입니다. 그래서 나중에 다른 규칙으로 쉽게 덮어쓰고 싶은 기본 스타일(예: 리셋 CSS, 컴포넌트 라이브러리의 기본값)은 `:where()`로 감싸두면, 사용하는 쪽에서 단일 클래스 선택자 하나로도 손쉽게 재정의할 수 있습니다.

```css
:where(.card, .panel) {
  border-radius: 8px; /* 명시도 0 → 어디서든 쉽게 덮어쓰기 가능 */
}
```

반대로 명시도를 유지한 채 선택자만 묶어 가독성을 높이고 싶다면 `:is()`가 적합합니다. 두 가상 클래스 모두 목록 안에 잘못된 선택자가 하나 섞여 있어도 `:is()`는 나머지를 무시하고 넘어가지만, `:where()`와 섞어 쓸 때도 이 동작은 동일하니 선택자 하나의 오타 때문에 전체 규칙이 깨질 걱정은 줄어듭니다.
