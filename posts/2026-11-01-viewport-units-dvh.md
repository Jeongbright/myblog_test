## 모바일 100vh 버그, dvh/svh/lvh로 해결하기

모바일 브라우저에서 `height: 100vh`인 전체 화면 레이아웃을 만들면, 주소창이 나타났다 사라질 때마다 레이아웃이 깜빡이며 잘리는 문제를 자주 겪습니다. `100vh`가 주소창을 포함한 최대 뷰포트 높이로 고정 계산되기 때문입니다. 이를 해결하기 위해 동적으로 변하는 뷰포트 높이를 반영하는 새 단위가 추가되었습니다.

```css
.full-screen {
  /* 구형 브라우저용 폴백 */
  height: 100vh;
  /* 주소창 유무에 따라 실시간으로 바뀌는 높이 */
  height: 100dvh;
}
```

`dvh`(dynamic viewport height)는 주소창 표시 상태에 맞춰 실시간으로 값이 바뀌어 콘텐츠가 가려지지 않습니다. 반면 `svh`(small viewport height)는 주소창이 보이는 가장 작은 상태, `lvh`(large viewport height)는 주소창이 숨겨진 가장 큰 상태로 고정된 값을 줍니다. 레이아웃이 계속 리플로우되길 원치 않는다면 `svh`로 작게 고정하는 편이 안전하고, 화면을 최대한 채우고 싶다면 `dvh`가 적합합니다. 구형 브라우저 지원을 위해 `100vh`를 먼저 쓰고 `100dvh`로 덮어쓰는 폴백 패턴을 권장합니다.
