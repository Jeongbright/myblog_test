## 전처리기 없이 CSS 네이티브 중첩(Nesting) 사용하기

Sass 같은 전처리기 없이도 이제 순수 CSS만으로 선택자를 중첩해서 쓸 수 있습니다. 모던 브라우저가 네이티브 CSS Nesting을 지원하면서, 반복되던 부모 선택자 타이핑과 별도 빌드 단계 없이 컴포넌트 단위 스타일을 더 읽기 쉽게 작성할 수 있게 됐습니다.

```css
.card {
  padding: 1rem;
  border-radius: 8px;

  & .title {
    font-size: 1.25rem;
    font-weight: 600;
  }

  &:hover {
    box-shadow: 0 4px 12px rgb(0 0 0 / 10%);
  }

  @media (min-width: 768px) {
    padding: 1.5rem;
  }
}
```

중첩된 규칙은 `&` 기호로 상위 선택자를 가리키며, `&`를 생략하고 자식 선택자(`.title` 등)만 써도 자동으로 하위 요소 선택자로 해석됩니다. 의사 클래스(`&:hover`)나 미디어 쿼리까지 블록 안에 그대로 넣을 수 있어 관련 스타일이 한곳에 모입니다. 다만 Sass 중첩과 달리 `&.foo`처럼 `&`를 생략하지 않고 명시해야 하는 경우가 있으므로, 전처리기 코드를 그대로 옮길 때는 선택자가 의도대로 합쳐지는지 확인이 필요합니다. 지원 브라우저가 Baseline 기준으로 충분히 넓어졌다면, 빌드 도구 설정 없이 바로 적용해볼 만합니다.
