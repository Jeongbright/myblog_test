## CSS scrollbar-gutter로 스크롤바 때문에 생기는 레이아웃 흔들림 막기

콘텐츠가 늘어나 스크롤바가 생기는 순간, 보이던 영역이 스크롤바 너비만큼 줄어들면서 레이아웃이 좌우로 흔들리는 경우가 있습니다. 특히 짧은 리스트에 항목을 추가하거나 필터링으로 콘텐츠 길이가 바뀌는 화면에서 두드러집니다. `scrollbar-gutter: stable`을 주면 스크롤바가 나타나지 않을 때도 그 자리를 미리 비워둬서, 스크롤바가 생기고 사라져도 콘텐츠 너비가 변하지 않습니다.

```css
.content {
  overflow-y: auto;
  scrollbar-gutter: stable;
}
```

양쪽 폭을 맞추고 싶다면 `both-edges` 키워드를 추가해, 스크롤바가 없는 반대쪽에도 같은 너비의 여백을 만들 수 있습니다.

```css
.content {
  overflow-y: auto;
  scrollbar-gutter: stable both-edges;
}
```

데스크톱처럼 스크롤바가 레이아웃 공간을 차지하는 환경에서 효과가 크고, 모바일처럼 오버레이 스크롤바를 쓰는 환경에서는 애초에 공간을 차지하지 않으므로 영향이 적습니다. `overflow`가 `auto`나 `scroll`인 요소에만 적용되며, 지원하지 않는 브라우저에서는 조용히 무시되어 별도 폴백 없이 점진적 개선으로 쓸 수 있습니다.
