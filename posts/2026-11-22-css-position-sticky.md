## CSS position: sticky로 스크롤 따라붙는 헤더·사이드바 만들기

테이블 헤더나 사이드바 제목처럼, 평소엔 문서 흐름대로 있다가 스크롤이 특정 지점을 지나면 화면에 붙어있어야 하는 요소가 있습니다. `position: fixed`와 스크롤 이벤트로 위치를 직접 계산하지 않아도, `position: sticky`와 임계값 속성 하나만으로 처리할 수 있습니다.

```css
thead th {
  position: sticky;
  top: 0;
  background: white; /* 아래 내용이 비치지 않도록 */
}
```

sticky 요소는 평소에는 `relative`처럼 동작하다가, 스크롤 중 지정한 `top` 값에 닿는 순간 `fixed`처럼 고정됩니다. 단, 고정 범위는 뷰포트 전체가 아니라 **가장 가까운 스크롤 가능한 조상 요소**의 영역으로 제한되며, 부모의 높이가 sticky 요소 자신과 같으면 붙어있을 공간이 없어 전혀 동작하지 않습니다. 또한 조상 중 하나라도 `overflow: hidden`, `scroll`, `auto`가 걸려 있으면 그 지점에서 고정 범위가 잘리므로, 레이아웃을 바꿨는데 sticky가 갑자기 안 먹힌다면 부모 체인의 overflow 속성부터 확인해보는 것이 좋습니다.
